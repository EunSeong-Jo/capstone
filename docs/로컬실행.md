# 로컬 단독 실행 (Windows)

AWS·Docker·Python·Node를 **따로 설치하지 않고**, `git clone` 한 뒤 `Swappy.bat` 한 번으로 서버와 휴대폰 크기 창을 띄웁니다.

```
git clone https://github.com/EunSeong-Jo/capstone.git
cd capstone
Swappy.bat          ← 더블클릭해도 됩니다
```

- **처음 한 번**은 Python(약 11MB), 백엔드 패키지(약 150MB), PostgreSQL(약 315MB)을 `.runtime/` 안에 내려받아 풉니다. 5~10분 걸립니다. 시스템에는 아무것도 설치하지 않습니다.
- 그다음 DB를 만들고 제품 데이터(약 6MB 덤프)를 복원한 뒤, 시연 계정과 시연 데이터를 채우고 Chrome(없으면 Edge) **앱 창**(주소창 없는 일반 크기 창)을 엽니다. 창 크기는 마우스로 조절할 수 있고, 앱 화면은 폰 모양 열이 가운데에 놓입니다.
- **창을 닫으면** 서버와 DB가 함께 종료됩니다. 두 번째 실행부터는 약 30초 안에 뜹니다.
- 인터넷이 필요합니다(첫 실행 내려받기, 제품 이미지).

## 계정
로그인 화면의 데모 계정 5개(`frontend/src/data/personas.json`)가 만들어집니다. 비밀번호는 모두 `swappy1234`입니다.
시연 흐름은 `eunseong@swappy.app`(조은성)이 기준입니다 — 화장대·찜·장바구니·주문·후기·AI 기억·얼굴 분석 기록(4건, 15항목 포함), 구독 상태.

## 명령
| 명령 | 동작 |
|---|---|
| `Swappy.bat` | 실행 |
| `Swappy.bat reset` | DB를 지우고 처음 상태로 다시 만든 뒤 실행(시연 데이터를 되돌릴 때) |
| `Swappy.bat stop` | 떠 있는 서버·DB 종료(창이 비정상 종료됐을 때) |

## 되는 것·안 되는 것
- 되는 것: 제품 검색·상세·성분 분석·성분 비교·대체품·예산 가이드·화장대·장바구니·주문·후기·피부 진단·피부 관리(저장된 표본 분석)·알림.
- **챗봇**은 키가 없으면 DB 기반 단순 답변만 합니다. AI 답변을 켜려면 프로젝트 루트에 `.env.local`을 만들고 `OPENAI_API_KEY=...`(또는 `ANTHROPIC_API_KEY=...`)를 적으세요(커밋 금지).
- **OCR**(사진으로 제품 찾기)과 **실제 얼굴 분석**은 외부 키가 필요해 꺼져 있습니다. 얼굴 분석은 저장된 표본으로 동작합니다.
- 폰 앱(APK)은 운영 서버 주소로 고정돼 있어 이 서버와 연결되지 않습니다.

## 문제 해결
| 증상 | 확인 |
|---|---|
| 내려받기 실패 | 네트워크가 python.org / bootstrap.pypa.io / get.enterprisedb.com 을 막는지 확인 |
| Windows 보안 경고 | "추가 정보 → 실행" (서명 없는 `.bat`) |
| 포트 사용 중 | 8800(서버), 55432(DB)를 쓰는 프로그램을 종료 |
| 서버가 안 뜸 | `.runtime\logs\backend.err.log` |
| DB 복원 실패 | `.runtime\logs\restore.log` |
| 경로에 한글·공백 | `C:\swappy` 같은 영문 경로로 옮기기를 권장 |

로그는 모두 `.runtime\logs\`에 있습니다. `.runtime/`은 git에 올라가지 않으며, 폴더를 지우면 처음 상태가 됩니다.

## 데이터·화면 갱신 (유지보수)
저장소에 들어 있는 `standalone/`의 파일은 **스냅샷**입니다. 바뀌면 다시 만들어 커밋합니다.

| 파일 | 만드는 법 |
|---|---|
| `standalone/catalog.dump.part*`, `reviews.dump`, `demo_analysis.dump` | `scripts/standalone/make_dump.sh` (운영 DB 읽기 전용, `.env.aws` 필요). 사용자 계정·주문·실제 후기는 들어가지 않고, 샘플 후기와 데모 얼굴 분석 기록만 포함 |
| `standalone/web.zip` | `scripts/standalone/make_web.sh` (프론트 빌드, 앱 설치 파일 제외) — **화면(`frontend/src`)이 바뀌면 다시 만들어야 합니다** |

덤프는 GitHub 파일 크기 제한을 피해 40MB 단위로 나눠 있고, 시작 스크립트가 이어 붙여 복원합니다.
