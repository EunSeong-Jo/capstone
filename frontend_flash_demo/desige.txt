motion_1 가이드
메인 색상: 초록 #2D7A4F 핑크 #F5C2C7 베이지 #F4E9D8
폰트: 미정임
디자인: 
(메인 화면 연결예정 페이지 아무대나 누르면 나오는 페이지로 일단 연결)
가운데 기본 이미지가 들어감 캐릭터 하단에 직사각형의 텍스트 박스가 띄워지면서 간단한 안내 맨트를 내보냄, 기본 캐릭터는 둥둥 떠다니는 듯한 모션을 줌
"안녕하세요 Swappy에 오신 여러분 환영합니다!!" -> "저는 여러분을 도와드릴 위피에요" -> "일단 여러분의 피부타입을 알기위해 몇가지 질문을 드릴께요~ 이미 피부 타입을 알고 계산가요?" / 텍스트 박스 아래에 두가지 버튼이 뜸 "알아요!", "아니요 몰라요"/
텍스트는 텍스트를 터치하면 넘어감, 텍스트 타자 쳐지듯이 텍스트가 나타남

알아요! 일때
캐릭터 "~타입" 이라고 되어있는 이미지들을 선택할수 있게 그리드 형태로 가운데 나타남 중앙에 모여있는 형태로 가운데 선택한 캐릭터와 그아래에 작은 글씨로 어떤 타입인지 텍스트 설명이 있음(이 텍스트는 일단 임의로 작성) 위치는 위에서부터 아래 순으로 / 선택된 케릭터 -> 캐릭터에 대한 설명 -> 캐릭터 선택 가능한 그리드 2x4(양옆에 공간 있어야함, 그리드선이 보여야함, 모서리는 둥글게 처리) -> 선택하기 버튼 순으로 있음/ 선택하기 버튼을 눌렀을때 메인화면(연결 예정)으로 넘어가게 만듬

아니요 몰라요 일때
메인화면 그데로 진행(기본 케릭터 있고 아래 텍스트 박스 형태) 기본 캐릭터 -> 기본_고민으로 바뀌고 그럼 같이 피부타입을 알아보아요! 맨트를 함, 그다음 터치를 하면 QnA가 나오는데 이거는 다른사람이 만들어서 일단 빈 공간으로 둠 , 한번더 터치하면 피부 타입을 분석하고 있어요 라는 맨트와 함게 기몬_고민 캐릭터가 있고 로딩이 되고 있다는 것을 표현함(여기는 너 마음대로 일단 만들어봐 로딩 페이지) 로딩이 끝나면 기본 결론 캐릭터가 나와서 00님의 타입은 ~타입이에요!! 하고 센터에 선택된 케릭터 그 아래에 어떤 캐릭터인지 부가적인 설명(임시로 작성) 하고 선택하기와 다시하기 버튼이 아래 있고 선택하기누르면 다시 메인화면으로 다시하기 버튼을 누르면 다시 QnA 형태로 나오도록 설정

임시로 나오는 타입은 조심조심 유리구슬 타입임

chatbot 가이드 (2026-07-20 추가, 담당: 주원)

위치: 홈 화면(메인 화면) 우하단 플로팅 버튼
색상: 초록 #2D7A4F (기존 메인 색상 그대로 사용)

동작 흐름:
홈 화면 우하단 녹색 챗봇 버튼 탭 → 챗봇 화면이 아래에서 슬라이드업으로 등장
챗봇 화면 상단: 베이지(#F4E9D8) 헤더, 'S' 아바타(초록 원), "Swappy 챗봇" / "화장품 성분 · 추천 전문" 텍스트, X 닫기 버튼
메시지 영역: 유저(초록 말풍선, 우측) / 봇(베이지 말풍선, 좌측 + S 아바타)
입력창: 하단 고정, 자동 높이 조절 textarea, 초록 전송 버튼

챗봇 기능:
- RAG(Retrieval-Augmented Generation) 방식: 질문 → 내부 제품 DB 검색 → LLM 답변 생성
- 피부 타입 컨텍스트 자동 주입 (온보딩 진단 결과 활용)
- 성분·효능·가격 비교 및 대체품 추천
- 할루시네이션 방지: DB에 없는 제품/성분은 답변하지 않음
- CoT(Chain of Thought) 프롬프팅 적용

백엔드 연동:
- POST /api/v1/chat
- 현재 LLM: Claude API (추후 교체 가능한 추상화 레이어 구조)
- 현재 DB: SQLite 테스트 DB (backend/data/products.db, 제품 10개)
- 추후: 올리브영/화해/식약처 실데이터로 교체 예정 — backend/app/services/rag.py의 search_products() 함수만 교체하면 됨

이모지 정책:
- 챗봇 UI 고정 문구(인사말, 오류 메시지 등)에는 이모지 사용 안 함
- LLM 답변의 이모지는 항목 번호(1️⃣2️⃣3️⃣)와 카테고리 구분에만 허용
