# 올리브영 모바일 앱 홈 화면 디자인 분석

> `대체뭐야` 홈 화면 리디자인을 위한 레퍼런스 분석 문서.
> 같은 폴더의 캡처 19장(`1.jpg` ~ `19.jpg`, 홈 스크롤 순서)을 근거로 작성했다.

---

## 0. 한 줄 요약

올리브영 앱의 디자인 정체성은 **"무채색 크롬(UI) + 제품 이미지가 컬러를 담당"**이다.
앱바·탭·칩·버튼 등 UI 요소는 철저히 **블랙 & 화이트**로 절제하고, 강조는 **할인율 레드** 정도만 사용한다. 굵은 블랙 한글 타이포로 강한 위계를 만들고, **개인화 큐레이션 섹션이 끝없이 반복**되는 정보 밀도 높은 커머스 레이아웃이다.

---

## 1. 컬러 시스템

UI 크롬은 무채색, 색은 제품/배너가 담당한다.

| 역할 | 값(근사) | 비고 |
|---|---|---|
| 기본 텍스트 | `#1A1A1A` ~ `#000` | 강한 블랙, 굵은 위계 |
| 보조 텍스트 | `#9A9A9A` / `#BDBDBD` | 회색 |
| 배경 | `#FFFFFF` | 흰색. 섹션 구분은 여백/얇은 회색선 |
| 활성 상태(칩·탭·탭바) | `#000000` | **선택 = 블랙 pill / 블랙 underline** |
| 할인율·세일 강조 | `#F8174A` 계열 | 선명한 핑크레드 (가격 % 표시) |
| N(신상)·장바구니·오특 뱃지 | 빨강(`#FF2D55` 계열) | 빨강 원/사각 |
| 순위 숫자 뱃지 | `#000` 사각 + 흰 숫자 | 1·2·3… |
| 태그 칩(BEST/쿠폰/오늘드림/증정) | 배경 `#F2F2F2` / 글씨 `#888` | 연회색 작은 라운드 사각 |
| 별점 ★ | 회색~`#FFB800` | 작게 |
| 좋아요(찜) | 회색 라인 하트 | 라인 아이콘 |

- 근거 캡처: 앱바·탭·카테고리 `1.jpg` / 할인율 레드·태그칩 `2.jpg`, `3.jpg` / 활성 블랙 pill `5.jpg`, `6.jpg` / 순위 블랙 사각 뱃지 `6.jpg`, `19.jpg`

---

## 2. 타이포그래피

강한 굵기 대비로 정보 위계를 만든다.

- **로고**: `OLIVE YOUNG` 이탤릭 볼드 영문 (`1.jpg`)
- **섹션 타이틀**: 한글 산세리프 **800~900 굵기**, 약 18–20px, 좌측 정렬
  - 예: "나를 위한 인기 상품"(`2.jpg`), "주목해야 할 브랜드"(`17.jpg`)
- **영문 섹션 타이틀 혼용**: "Weekly Special"(`3.jpg`, `4.jpg`) 산세리프 볼드
- **상품명**: 14px 보통 굵기, **2줄 말줄임(line-clamp-2)**
- **가격**: 볼드 16px, 할인율 `%`는 같은 줄에 **레드 강조**
- 전반 무드: 굵은 블랙 한글 + 높은 정보 밀도. Pretendard 계열로 재현 가능.

## 3. 레이아웃 · 컴포넌트 패턴

- 좌우 패딩 16px, 섹션 간 큰 여백 + 띠배너로 리듬
- 모서리: 카드 12~16px / 배너 16~20px / **pill 버튼·칩 = full(999px)**

| 컴포넌트 | 설명 | 근거 |
|---|---|---|
| **상단 앱바** | 로고 + 드롭다운(▼ 블랙 사각) / 우측 검색·알림·장바구니(빨강 카운트 뱃지) | `1.jpg` |
| **상단 탭 메뉴** | 가로 스크롤(맨즈추천·홈·오특·랭킹·세일·기획전), 활성 = 블랙 볼드 + underline | `1.jpg`~ 전체 상단 고정 |
| **메인 배너 캐러셀** | 그라데이션 배경 + 제품 누끼 + 카피, 좌우 peek, 인디케이터 `01 \| 17 +` 숫자형 | `1.jpg` |
| **카테고리 아이콘 그리드** | 2행×5열, 정사각 라운드 썸네일 + 라벨, 일부 `N` 뱃지 | `1.jpg` |
| **칩 필터** | 가로 스크롤 pill. 활성 = 블랙 배경 흰 글씨 / 비활성 = 흰 배경 회색 테두리 | `3.jpg`, `5.jpg`, `19.jpg` |
| **상품 카드(세로)** | 정사각 라운드 이미지 + 상품명 2줄 + 할인율(레드)·가격(볼드) + 태그칩 + 별점(리뷰수) + 찜♡/장바구니🛍 | `2.jpg`, `3.jpg`, `7.jpg` |
| **상품 행(가로형 리스트)** | 좌측 순위/순번 뱃지 + 썸네일 + 상품명 + 할인/가격 + 태그칩 + 찜 | `6.jpg`, `14.jpg`, `15.jpg` |
| **순위 리스트** | 1·2·3 블랙 사각 숫자 뱃지 + 페이지네이션(`< 19 \| 20 >`) | `6.jpg`, `19.jpg` |
| **"더보기"** | 우측 상단 `더보기 >` 텍스트 / 섹션 하단 중앙 pill(`테마 더보기 1\|5`) | `5.jpg`, `8.jpg`, `9.jpg` |
| **매거진 카드** | 2열, 큰 이미지 + 제목 2줄, "매거진 더 보러가기" pill | `12.jpg` |
| **풀폭 배너 스택** | "오직 올리브영에서만" 라운드 배너 3개 세로 스택, 좌측 텍스트 | `13.jpg` |
| **대형 단일 배너** | "신상 업데이트" 풀폭 대형 이미지 + 제목/서브 + "신상 더보기 1\|7" pill | `15.jpg` |
| **브랜드 섹션** | 브랜드 칩 탭 + 브랜드 대표 배너(좋아요 수) + 상품 리스트 + 페이지네이션 | `17.jpg` |
| **라이브 카드** | "올영라이브" 가로 스크롤, 시간 + 제목 오버레이 | `19.jpg` |

## 5. `대체뭐야`에 이식할 핵심 요소 (후속 적용 가이드)

우리 앱은 화장품 **성분 기반 대체품 추천**이 본질이므로, 올리브영 커머스 섹션을 그대로 복제하기보다 **디자인 언어**를 차용한다.

### 컬러 방향 (확정)
**무채색(블랙 & 화이트) 베이스 + 기존 브랜드 녹색(`#3D8F6F`)을 포인트로 유지.**
- UI 크롬·타이포·활성 상태 → 블랙 계열 (올리브영식)
- 브랜드 정체성 포인트(로고 강조, 일부 활성 표시 등) → 녹색
- 할인율·세일 강조 → 올리브영식 레드 활용 가능

### 차용 컴포넌트/섹션 매핑
- **앱바**: 로고 + 검색/알림 (블랙 라인 아이콘)
- **상단 가로 탭** 또는 **카테고리 아이콘 그리드(2행×5열)**
- **"나를 위한 인기 상품"**: 피부타입 기반 추천 가로 캐러셀
- **실시간 인기 순위**: 블랙 사각 순위 뱃지 행 리스트
- **칩 필터**: 활성 = 블랙 pill
- **상품 카드/행**: 할인율 레드 + 태그칩 + 찜
- **풀폭 배너**로 섹션 리듬

### 재사용 가능한 기존 자산
- `frontend/src/components/home/RankingList.tsx`, `RankingProductCard.tsx` — 순위 리스트(블랙 사각 뱃지로 스타일 조정)
- `frontend/src/components/home/CategoryScroller.tsx` — 카테고리(그리드형으로 변형 가능)
- `frontend/src/components/home/SectionHeader.tsx` — 섹션 헤더(좌측 정렬 굵은 타이포)
- `frontend/src/components/product/ProductCard.tsx` — 상품 카드 베이스
- `frontend/src/mocks/home.ts` — mock 데이터(섹션 구성에 맞게 확장)

### 다음 단계에서 확정할 사항
- `atelier-*` 토큰/`home/` 컴포넌트를 올리브영 스타일로 교체할지 재사용할지
- 하단 탭바 활성색(블랙 vs 녹색 포인트)
- 도입할 섹션 범위(모든 큐레이션 섹션 vs 핵심 4~5개)
