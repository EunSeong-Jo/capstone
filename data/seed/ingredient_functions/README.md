# 성분 기능 분류 (ingredient_functions)

제품에 쓰이는 성분 4,277종 중 **1,686종**(제품 출현 기준 94.4%)을 **화장품 성분 전문가의 관점**에서 한 번만 분류해 둔 데이터다. 나머지 약 2,600종은 1~2회만 나오는 꼬리 성분(식물추출물·고분자·철자 변형)이라 라벨이 없고, 라벨 없는 성분은 유사도에서 `tfidf` 항으로만 기여하며 궁합 판정 근거에서는 빠진다. 오염된 이름(제품명·함량·색상번호 혼입) 153종은 규칙으로 `role=j`를 달았다. 유사도(`hybrid`)와 피부 궁합(`skin_fit`)이
같이 쓴다. 분류는 AI(Claude)가 직접 읽고 판정했고(`source=ai_expert`), 사람이 확인한 행은 `reviewed`로 바꾼다.

## 왜 기존 `tags`를 쓰지 않는가

`tags`(11개)는 피부타입 규칙(`skin_type_rules`)이 이름으로 참조하는 어휘라 바꾸면 규칙이 조용히 어긋난다. 게다가 키워드
`ILIKE`로 붙인 태그라 **과대·과소 포함이 있다**(예: 베타인 계면활성제가 '보습', 에틸헥실글리세린이 '보습', 마데카소사이드가
'피지·모공'). 그래서 `tags`는 그대로 두고 새 분류표를 따로 둔다. 420종에 기존 태그가 붙어 있어 일치도 점검에만 썼다.

## 분류표 v1

| 구분 | 코드 | 뜻 |
|---|---|---|
| 기능(복수) | `H` | 보습 — 습윤제(글리세린·히알루론산·베타인), **에몰리언트·오일·버터(시어버터·호호바·스쿠알란)**, 보습 펩타이드·콜라겐 |
| | `B` | 장벽 — 세라마이드·콜레스테롤·지방산·피토스핑고신, 판테놀 등 장벽 회복 |
| | `S` | 진정 — 병풀·마데카소사이드·알란토인·비사보롤·아줄렌·감초 등 항염·진정 |
| | `W` | 미백·톤 — 나이아신아마이드·비타민C 유도체·알부틴·트라넥삼산·코직애씨드·감초 |
| | `A` | 주름·탄력 — 레티노이드·펩타이드(신호·전달)·아데노신·EGF·바쿠치올·콜라겐(탄력 목적) |
| | `O` | 항산화 — 토코페롤·유비퀴논·녹차·폴리페놀 추출물·글루타티온 |
| | `P` | 피지·모공 — BHA·징크피씨에이·티트리·클레이·숯·실리카(피지 흡착) |
| | `E` | 각질·클렌징 — AHA·BHA(각질 목적)·효소·우레아(각질 연화) |
| | `U` | 자외선 차단 |
| 역할(1개) | `a` | 활성 — 위 기능 중 하나 이상을 내는 성분 |
| | `e` | 에몰리언트·오일·버터(기능이 보습이면 `H`도 함께 붙인다) |
| | `s` | 용매·습윤 베이스(정제수·글리세린·부틸렌글라이콜·알코올) |
| | `f` | 계면활성·유화 |
| | `t` | 점증·안정화·겔화 |
| | `p` | 방부·보존(방부 보조제 에틸헥실글리세린·1,2-헥산다이올 포함) |
| | `x` | 기타 — 향료·색소·pH 조절·킬레이트·쿨링제 |
| | `j` | **오염** — 제품명·색상 번호가 섞여 성분으로 쓸 수 없는 행(분류 제외) |
| 플래그(복수) | `I` | 자극 소지(변성·무수 알코올, 일부 에센셜 오일, 고농도 산 계열 성분) |
| | `F` | 향료·식약처 지정 알레르기 유발 향료 25종 계열 |
| | `L` | 건조 알코올(에탄올·변성알코올) |

`source`: `ai_expert`(AI가 성분 지식으로 판정) · `reviewed`(사람 검수) · `mfds`(식약처 고시 목록) · `cosing`(EU CosIng 확인).
`allergen_listed`: 식약처 고시 목록의 성분이면 1. 화면의 "알레르기 유발" 표시와 피부타입 필터의 하드 제외는 **이것만** 근거로 한다(목록 밖 향료 의심은 감점·"주의" 표시까지만).

> **목록 출처 주의**: `allergens_mfds.csv`는 저장소의 `data/seed/skin_type_ingredients/exclusion_criteria.csv`(별표2 "착향제 중 표시 의무")를 옮긴 것이고, INCI명은 AI가 붙였다. 고시 원문과 대조하지는 못했다(26번째 항목 HICC는 공식 25종과 다른 것으로 보인다).

확신도: `3` 확실(성분 정체와 기능이 알려져 있음) · `2` 보통(유래·계열로 추정) · `1` 낮음(이름만 있고 근거 부족 — 검수 대상, 궁합 판정 근거에서 제외).

## 판정 지침

- **기능은 흔한 용도 기준**이다. 같은 성분이 여러 일을 해도 화장품에서 그 성분을 쓰는 주된 이유 1~3개만 붙인다.
- **에몰리언트·오일·버터는 `H`를 붙인다**(역할 `e`). 보습 효과가 곧 쓰는 이유다. 장벽 지질이면 `B`도.
- **식물추출물·발효여과물**은 식물/균주의 알려진 효능으로 분류하되, 근거가 약하면 확신도 1~2. 추출물·수·오일·가루·소포는 같은 기능이지만
  오일은 역할 `e`, 나머지는 `a`.
- **펩타이드**는 이름의 계열로 판정: 신호·전달·보톡스 유사 펩타이드(`A`), 미백 펩타이드(`W`), 진정 펩타이드(`S`). 근거가 없으면 `A`, 확신도 2~1.
- **계면활성 베타인류(코카미도프로필베타인 등)** 는 `f`다. 보습이 아니다(기존 태그가 키워드 때문에 `H`로 잡은 것과 다르다).
- **향료 계열**은 `x` + `F`. 알레르기 유발 향료 25종(리날룰·리모넨·시트랄 등)은 확신도 3. 에센셜 오일은 활성이면 기능을 붙이고 `F`·`I`를 단다.
- **오염된 행**(제품명, 색상·호수 번호, 용량·ppm 표기)은 `j`로 두고 `note`에 이유를 적는다. 정체가 분명한 오타·변형은 본래 성분으로 분류하고
  확신도 1~2 + `note`.
- 이름만 있고 설명이 없는 성분은 알려진 INCI 지식으로만 판단하고 모르면 `x`·확신도 1.
