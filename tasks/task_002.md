# Task ID: 2

**Title:** 제품 데이터 수집기 개발

**Status:** pending

**Dependencies:** 1 ⧖

**Priority:** high

**Description:** 식약처 API와 올리브영 크롤러를 통해 제품 데이터를 수집합니다.

**Details:**

Python 스크립트를 작성하여 식약처 API에서 제품 데이터를 수집합니다. Selenium과 BeautifulSoup을 사용하여 올리브영 웹사이트에서 제품 정보를 크롤링합니다. 수집된 데이터를 PostgreSQL에 저장합니다. PRD v1.8 요구사항에 따라 8가지 피부타입(옹달샘/물개/수부지/화산/사막/인절미/유리구슬/메밀묵)별 추천/주의 성분 매핑 룰 데이터와 피부타입별 사전 큐레이션 세트 데이터를 구축합니다.

**Test Strategy:**

수집된 데이터의 품질을 검증하기 위해 샘플 데이터를 수동으로 확인합니다. 데이터베이스에 저장된 데이터의 일관성을 체크합니다. 피부타입 매핑 커버리지(각 타입당 추천 가능 제품 카테고리별 50개 이상) 달성 여부를 확인합니다.

**Status:** pending

### 2.3. 수집된 데이터 PostgreSQL에 저장

### 2.9. 피부타입-성분 매핑 룰 데이터 구축

**Status:** pending  
**Dependencies:** 2.6, 2.7  

8가지 피부타입별 추천/주의 성분 태그 매핑 데이터를 skin_type_mapping_rules 테이블에 구축합니다.

**Details:**

PRD v1.8 요구사항에 따라 8가지 피부타입(수분팡팡 옹달샘, 반질반질 물개, 겉바속촉 수부지, 울긋불긋 화산, 바스락 사막, 말랑말랑 인절미, 조심조심 유리구슬, 얼룩덜룩 메밀묵)별로 추천 성분 태그 5~10종과 주의 성분 태그 3~5종을 매핑합니다. 소스: 대한피부과의사회 자료, 화해 뷰티앱 피부타입별 추천 컨텐츠, 가능 시 피부과 전문의 자문. skin_type_mapping_rules 테이블에 skin_type(8타입 enum), condition(JSON: 5축 점수 조건), recommended_tags(JSON: 추천 성분 기능 태그), avoid_tags(JSON: 주의 성분 태그) 컬럼을 구성합니다. 예시 매핑: 옹달샘→[균형보습, 항산화, 가벼운유분], 물개→[살리실산, 가벼운제형, 논코메도제닉], 화산→[시카, 판테놀, 진정성분] / 화산 주의→[알코올]. 매핑 룰 초안 작성 후 팀 내 리뷰와 외부 자료 교차 검증을 진행합니다.

### 2.10. 피부타입별 사전 큐레이션 세트 구축

**Status:** pending  
**Dependencies:** 2.9  

각 피부타입별 기본 3종 세트(스킨/로션/에센스)를 admin_curated_sets 테이블에 사전 큐레이션합니다.

**Details:**

PRD v1.8 요구사항에 따라 8가지 피부타입별로 가입 직후 환영 팝업에 노출될 추천 세트를 사전 정의합니다. admin_curated_sets 테이블에 skin_type, set_name(예: '옹달샘 균형 케어 입문 세트'), product_ids(JSON: [123, 456, 789]), price_tier(low/mid/high), description, is_active 컬럼을 구성합니다. 큐레이션 기준: 해당 피부타입의 추천 성분 태그 충족 + 가격대 분산(저가/중가/고가 세트 각 1개) + 별점 4.0 이상 제품으로 구성. 각 타입별 최소 3개 세트(가격대별)를 준비하여 총 24개 이상의 큐레이션 세트를 구축합니다. 콜드 스타트 대응을 위해 신규 가입 사용자에게 즉시 추천 가능한 상태로 유지합니다.
