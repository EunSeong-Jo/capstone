# Task ID: 8

**Title:** 성분 필터링 기능 개발

**Status:** pending

**Dependencies:** 6

**Priority:** medium

**Description:** 사용자가 특정 성분을 제외하고 대체품을 검색할 수 있는 기능을 개발합니다.

**Details:**

프론트엔드에 필터 UI를 추가하고, 백엔드에서 필터 조건에 맞는 제품을 검색하는 기능을 구현합니다.

**Test Strategy:**

필터링 조건을 변경하며 검색 결과가 올바르게 반영되는지 확인합니다. 다양한 필터 조합으로 테스트하여 안정성을 검증합니다.

## Subtasks

### 8.1. 프론트엔드 필터 UI 디자인

**Status:** pending  
**Dependencies:** None  

사용자가 특정 성분을 제외할 수 있도록 필터 UI를 디자인합니다.

**Details:**

사용자 경험을 고려하여 필터 UI를 직관적으로 설계합니다. 필터 옵션은 드롭다운 메뉴와 체크박스를 사용하여 구현합니다.

### 8.2. 프론트엔드 필터 UI 구현

**Status:** pending  
**Dependencies:** 8.1  

디자인된 필터 UI를 실제 코드로 구현합니다.

**Details:**

React를 사용하여 필터 UI를 구현하고, 상태 관리를 위해 Redux를 적용합니다. 필터링 조건을 변경할 수 있도록 이벤트 핸들러를 설정합니다.

### 8.3. 백엔드 필터링 로직 개발

**Status:** pending  
**Dependencies:** 8.1  

사용자가 선택한 필터 조건에 맞는 제품을 검색하는 백엔드 로직을 개발합니다.

**Details:**

FastAPI를 사용하여 필터 조건을 처리하고, PostgreSQL에서 해당 조건에 맞는 제품을 쿼리하는 API 엔드포인트를 구현합니다.

### 8.4. 프론트엔드와 백엔드 통합

**Status:** pending  
**Dependencies:** 8.2, 8.3  

프론트엔드 필터 UI와 백엔드 API를 통합하여 필터링 기능을 완성합니다.

**Details:**

Axios를 사용하여 프론트엔드에서 백엔드 API를 호출하고, 필터링된 결과를 UI에 표시합니다. 데이터 흐름을 확인합니다.

### 8.5. 테스트 및 버그 수정

**Status:** pending  
**Dependencies:** 8.4  

필터링 기능을 테스트하고 발견된 버그를 수정합니다.

**Details:**

다양한 필터 조합을 사용하여 검색 결과가 올바르게 반영되는지 확인합니다. 발견된 버그는 우선순위에 따라 수정합니다.
